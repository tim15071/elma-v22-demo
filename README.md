# ЭЛМА Выборгская — демо навигации

[Открыть приложение](https://tim15071.github.io/elma-v22-demo/)

Демонстрация интерактивной панели бизнес-парка: исходная схема ЭЛМА, вращаемая 3D-модель территории, поиск организаций, карточки строений и планы этажей.

Выберите организацию в каталоге, откройте её карточку и нажмите «Построить маршрут». Для просмотра территории переключитесь в 3D.

Это демонстрационная версия 0.11.0 для согласования интерфейса. Пешеходные маршруты и входы предварительные и требуют проверки на территории. Внутренняя навигация по помещениям и подключение к рабочему кабинету в этом демо не выполняются.

## Материалы

- Схема, логотип и поэтажные планы ЭЛМА предоставлены для разработки панели; права на материалы принадлежат их владельцам.
- Геометрия территории: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL 1.0. Исходная геометрия доступна в `elma/geometry-sources.geojson`.
- 3D-модель содержит визуальные реконструкции и не является обмерным чертежом.

В этом репозитории размещена готовая статическая сборка для GitHub Pages.
