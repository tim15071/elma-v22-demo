# ЭЛМА Выборгская — демо навигации

[Открыть приложение](https://tim15071.github.io/elma-v22-demo/)

Демонстрация интерактивной панели бизнес-парка: исходная схема ЭЛМА, вращаемая 3D-модель территории, поиск организаций, карточки строений и планы этажей.

Выберите организацию в каталоге, откройте её карточку и нажмите «Построить маршрут». Для просмотра территории переключитесь в 3D.

Это демонстрационная версия 0.12.1 для согласования интерфейса. В поэтажных планах подсвечиваются 109 областей для 86 из 108 размещений арендаторов. Откройте карточку организации и нажмите «Открыть план этажа»; в списке этажа можно выбрать другую организацию.

Пешеходные маршруты и входы предварительные и требуют проверки на территории. Переключатель «Проверить перекрытие» демонстрирует обход закрытого прохода. Путь внутри здания пока не нанесён; для 22 размещений точное помещение ещё уточняется.

Публичный просмотр опубликованного маршрута поддерживает QR-ссылку с организацией и планом этажа. Для рабочего режима нужны опубликованный проект и сервер ИскраСкрин. Обычный запуск демо использует демонстрационные данные и не подключает экран к рабочему кабинету.

## Материалы

- Схема, логотип и поэтажные планы ЭЛМА предоставлены для разработки панели; права на материалы принадлежат их владельцам.
- Геометрия территории: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL 1.0. Исходная геометрия доступна в `elma/geometry-sources.geojson`.
- 3D-модель содержит визуальные реконструкции и не является обмерным чертежом.
